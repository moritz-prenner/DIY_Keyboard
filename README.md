# DIY_Keyboard 

This project is a full size Keyboard powered by a rp2040 pro micro and a custom pcb designed by myself :)
After I am going to build it it should (hopefully) function like a regular storebought keyboard. It even contains a knob to control volume for example.
I built this project to get better at pcb design and learn something new about keyboard firmware.
